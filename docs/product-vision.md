# Product Vision

## Product Name

SetPilot

## Vision

SetPilot helps gym users execute structured workout programs with confidence and consistency.

Many beginner-to-intermediate gym users have a workout plan but struggle with execution: remembering what to do, understanding movements, timing rest, recording set performance, and seeing whether they are progressing. SetPilot should act as a focused workout companion during the session.

## Target User

Beginner-to-intermediate gym users who:

- Already have or want a structured workout plan.
- Need help following the plan in the gym.
- Want simple exercise guidance without a full coaching product.
- Want to track set performance without complicated spreadsheets.
- Want basic feedback after each workout.

## Core Jobs To Be Done

- When I arrive at the gym, I want to open my planned workout so I know exactly what to do.
- When I see an exercise, I want quick access to example videos so I can understand the movement.
- When I complete a set, I want to record weight, reps, and difficulty quickly.
- When I rest, I want a timer so I stay on track.
- When I finish, I want a summary so I know what I completed and how I performed.
- Over time, I want to see whether I am progressing.

## Product Principles

- Execution first: prioritize the workout session experience over planning complexity.
- Simple structure: programs, days, exercises, sets, and sessions should be easy to understand.
- Curated guidance: YouTube examples should be stored and selected intentionally, not generated automatically.
- Low friction tracking: recording a set should be fast during a workout.
- Local MVP first: use SQLite locally before introducing production infrastructure.

## Non-Goals For MVP

- No AI-generated workout planning.
- No authentication.
- No trainer dashboard.
- No payments.
- No nutrition tracking.
- No smartwatch sync.
- No social feed or sharing.
